# Auth 
 **Auth** - блок регистрации/авторизации пользователей, пользователь авторизуется с помощью JWT токенов, при регистрации происходит хэширование пароля пользователя, при авторизации пароль сверяется с сохранённым хэшем
1. JWT token - используется для безопасной передачи данные в JSON формате, он же access токен
2. refresh token - специальный долгоживущий ключ, который используется для получения нового короткоживущего (access) токена, без обязательного ввода пароля и логина повторно
---

## Модели данных
В блоке **Auth**, реализованы 2 типа данных:
1. User - ```type User struct {
	Id           string    `db:"id"`
	Name         string    `db:"name"`
	Email        string    `db:"email"`
	PasswordHash string    `db:"password_hash"`
	Role         string    `db:"role"`
	CreatedAt    time.Time `db:"created_at"`
}``` тип данных, описывает пользователя, все его данные которы требуются для корректно работы программы


2. RefreshToken - ```type RefreshToken struct {
   Id        string     `db:"id"`
   UserId    string     `db:"user_id"`
   TokenHash string     `db:"token_hash"`
   ExpiresAt time.Time  `db:"expires_at"`
   RevokedAt *time.Time `db:"revoked_at"`
   CreatedAt time.Time  `db:"created_at"`
   }```

## Нетривиальные методы

```Refresh``` - метод пересборки токенов с нетривиальной логикой, внутри себя метод, получает токен по его хэшу, проверяет что токен не был отозван и не истек, получает пользователя по id, генерирует новые access и refresh токены, открывает транзакцию, в рамках которой отзывает старый токен и сохраняет новый в базу

**Транзакция(Unit of Work)** - паттерн обеспечивающий атомарность операций, например если не использовать транзакцию, при вызове эндпоинта refresh, в случае если revoke отработает успешно, а create следом упадет с ошибкой, старый токен останется отозванным, а новый не создастся - пользователь потеряет возможность обновить сессию и будет вынужден логиниться заново, транзакция же гарантирует, что если упадет create, revoke тоже откатится и пользователь не окажется в таком промежуточном состоянии
